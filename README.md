# Daily Check

Sistema de organização de tarefas com integração de previsão do tempo em tempo real.

O **Daily Check** permite criar, listar e excluir tarefas enquanto exibe o clima atual de qualquer cidade usando API externa.

O projeto foi desenvolvido utilizando **HTML, CSS, JavaScript, Node.js, Prisma e MySQL (MariaDB)**.

---

## Demonstração do projeto

- Página de tarefas e clima integrados  
- Interface simples e funcional  
- Consumo de API externa (OpenWeatherMap)  
- CRUD completo de tarefas  

---

## Funcionalidades

### Clima
- Consulta de temperatura em tempo real
- Integração com API OpenWeatherMap
- Exibição de:
  - Temperatura
  - Umidade
  - Descrição do clima
  - Ícone do tempo

### Tarefas
- Criar tarefas
- Listar tarefas
- Excluir tarefas
- Cadastro com:
  - Nome
  - Descrição
  - Data de início
  - Data de fim
  - Imagem
